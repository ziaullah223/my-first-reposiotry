# Titanic Dataset - Machine Learning Project

This is my first machine learning project using the Titanic dataset.

## About the Project

In this project, I perform data analysis, data preprocessing, visualization, and machine learning on the Titanic dataset.

## Main Steps

- Load the Titanic training and test datasets
- Explore and analyse the data
- Create visualizations using Matplotlib
- Extract useful information from the `Name` column
- Handle missing values
- Apply One-Hot Encoding
- Apply Standard Scaling
- Split data into training and validation sets
- Train Logistic Regression
- Train Random Forest
- Compare model performance

## Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Jupyter Notebook

## Dataset

The project uses:

- `train.csv`
- `test.csv`

The training dataset contains the `Survived` target column.
